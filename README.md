# TM470 Mushroom CNN Comparison

This project compares multiple CNN architectures for mushroom image classification as part of TM470.

## Project Aim
To compare the performance of different CNN models on the same mushroom image dataset using consistent evaluation criteria.

## Models
- Baseline CNN
- ResNet
- MobileNet

## Evaluation Criteria
- Accuracy
- Precision
- Recall
- F1-score
- Training time
- Validation performance

## Structure
- `data/` dataset files
- `src/` training and evaluation scripts
- `notebooks/` experimentation
- `results/` outputs and figures
- `docs/` project notes and references
